# Examples

A fully-offline walkthrough of `bitwig-nitro-tools`. Nothing here needs a
Bitwig installation, decrypted DSP content, or any cipher key. Everything is
built from the public builder DSL.

## Files

| File | What it is |
|------|-----------|
| `synthetic_module.nitrobin` | A committed, synthetic Nitro module (`synthetic_gain`), a two-port value component with one tunable float default. Generated by `walkthrough.py`'s `build()`, not extracted from Bitwig. |
| `walkthrough.py` | Runs the full pipeline end-to-end: author, serialize, decompile, pretty-print, then edit. |

## Decompile the synthetic module

Once the package is installed (`pip install -e .`), the `nitro-decompile`
console script reads a decrypted `.nitrobin` and prints its pseudo-source:

```console
$ nitro-decompile examples/synthetic_module.nitrobin
```

Expected output (excerpt):

```
struct synthetic_gain
{
    value_inport in;
    value_outport out;
}
```

The same decompilation is available directly from the library. This one-liner
needs only the standard library plus the package, no CLI entry point:

```console
$ python -c "from bitwig_nitro import decompile_nitrobin, pretty_print; \
print(pretty_print(decompile_nitrobin(open('examples/synthetic_module.nitrobin','rb').read())), end='')"
```

## Run the full walkthrough

```console
$ python examples/walkthrough.py
# built synthetic_gain -> 129 bytes

# pretty_print():

struct synthetic_gain
{
    value_inport in;
    value_outport out;
}

# constant at path 0.0.1.1.5.1: 0.5
# mutated 0.5 -> 0.25; same size: True
# matches committed synthetic_module.nitrobin: True
```

## What it demonstrates

1. **Author** a module tree with the builder DSL (`bitwig_nitro.nitro_builder`).
2. **Serialize** it to `.nitrobin` bytes (`serialize_nitrobin`).
3. **Decompile** those bytes back to an AST (`decompile_nitrobin`) and
   **pretty-print** it (`pretty_print`).
4. **Address** a numeric literal by path (`find_constants_in_bytes`) and
   **mutate it in place at the same byte width** (`mutate_constant_bytes`),
   the property that lets a changed constant drop back into a repacked archive
   without shifting anything else.

To decrypt or repack a real `nitro-image` from your own Bitwig install you must
supply your own keys. See [`docs/KEY_EXTRACTION.md`](../docs/KEY_EXTRACTION.md)
and `bitwig_nitro.keys`.
